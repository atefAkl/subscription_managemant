===================================
TROUBLESHOOTING
===================================

❌ ERR_NGROK_3200 (Endpoint offline):
   → Check if WAMP is running
   → Verify Apache is on port 80
   
❌ 404 Not Found:
   → .htaccess should redirect automatically
   → Check if mod_rewrite is enabled in Apache
   
❌ Assets not loading:
   → APP_URL must match ngrok URL
   → Run: php artisan config:clear
